1. What is Ransomware?
Malware classification and attack anatomy

Ransomware is a category of malicious software that blocks access to a victim's computer system or encrypts their files, demanding a ransom payment (typically in cryptocurrency like Bitcoin or Monero) to provide the decryption key.

Crypto Ransomware
Silently locates high-value files (documents, databases, photos) and encrypts them using strong ciphers (e.g., AES-256 + RSA-4096), appending extensions like .locked.
Locker Ransomware
Locks the victim out of the operating system interface entirely, displaying full-screen ransom demands without necessarily encrypting underlying disk blocks.
Common Early Warning Signs:
  • Sudden spike in disk I/O operations and CPU utilization by unknown processes.
  • Rapid renaming of multiple files with foreign, unrecognized extensions.
  • Presence of new text or HTML instruction files (e.g., README_RESTORE_FILES.txt).
  • Spontaneous termination of security tools, volume shadow copies, and backup agents.
2. Behavioral vs. Signature Detection
Next-Generation Antivirus (NGAV) methodologies

Traditional antivirus tools rely primarily on static signatures (MD5/SHA256 hashes of known malware executables). Attackers easily bypass signatures by recompiling their code, altering packers, or using polymorphic engines.

Criterion Signature-Based Behavioral Heuristics (Our System)
Zero-Day Attacks Fails (No signature exists) Effective (Identifies actions)
Detection Basis Static file checksum In-flight I/O patterns & velocities
Speed of Defense Requires signature update Instant automated containment

Our simulator implements sliding-window behavioral analysis. Instead of inspecting file contents (which protects privacy and performance), it continuously monitors operation velocity, rapid renaming patterns, and extension tampering.

3. Mathematical Threat Scoring
Transparent multi-factor heuristic calculation

Rather than acting as a black box, the detection engine produces an explainable threat score from 0 to 100 based on weighted behavioral components:

Score = min(100, S_rename + S_extension + S_burst + S_velocity)
• S_rename (Max 35 pts): min(35.0, (Renames_in_Window / Threshold_rename) × 35.0)
• S_extension (Max 40 pts): Triggered whenever file extensions are switched to known ransomware patterns (e.g., .locked).
• S_burst (Max 25 pts): min(25.0, (Modifications_in_Window / Threshold_mod) × 25.0)
• Severity Tiers: Low (0–29), Medium (30–59), High (60–79), Critical (80–100).
4. Recovery & Defense in Depth
The 3-2-1 backup paradigm and enterprise defenses
The Golden 3-2-1 Backup Rule:
3
Copies of all critical business data
2
Different storage media types (SSD, Tape)
1
Offsite, air-gapped or immutable copy
Core Defensive Hygiene:
  • Principle of Least Privilege (PoLP): Restrict write access to network shares.
  • Network Segmentation: Isolate critical operational databases from employee workstations.
  • Multi-Factor Authentication (MFA): Mandate MFA on all remote desktop (RDP) access.
  • Patch Management: Regularly patch operating systems and applications to close CVEs.
